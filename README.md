Das ist mein README, wenn Sie diese Schritte machen dann wird das Programm laufen.

Voraussetzungen die man am Computer braucht:
1. JAVA JDK (Version 8 oder später)
2. Eine IDE mit Maven-Unterstützung (ich habe Intellij verwendet)

1. Schritt nach dem Herunterladen:
--> Die Zugangsdaten prüfen in der DatabaseManager.java das Passwort eingeben, damit man sich mit der mysql DB verbinden kann.

2. Schritt: eine leere Datenbank anlegen
--> Die MySql Workbench und erstellen Sie eine komplett leere Datenbank mit diesem Befehl: CREATE DATABASE airline_db;

3. Schritt: Überprüfen
--> Sobald das Projekt installiert ist, eine kurze Zeit warten damit die pom.xml alles laden kann.

4. Schritt: Das Programm starten
--> Die Klasse models.Main öffnen und das Programm einfach ausführen.
